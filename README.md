# Token Clicker

Браузерная idle/clicker-игра в духе Cookie Clicker: игрок нанимает настоящие ИИ-модели, они
генерируют Токены, а переход в следующее Поколение открывает Престиж.

Одна страница на React без бэкенда и аккаунтов: прогресс лежит в `localStorage` этого браузера,
поэтому каждый origin — своя игра.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173 (Vite сам возьмёт свободный порт)
npm test         # 373 теста, vitest
npx tsc -b       # единственный статический контроль типа
```

## Как играть

| Действие | Где |
| --- | --- |
| **Клик** — «Отправить промпт», даёт Токены и изредка реплику Модели | колонка «Промпт» |
| **Агенты** — купить копии Моделей, они сами генерируют Доход | вкладка «Модели» |
| **Апгрейды** — постоянные множители Дохода и Клика, сгорают при Престиже | вкладка «Апгрейды» |
| **Престиж** — сбросить Забег ради Compute и следующего Поколения | вкладка «Престиж» |
| **Событие** — поймать Золотой Токен, пока висит окно | поверх Сцены |
| **Глюки** — три клика, и возвращают всё, что успели украсть | Сцена |

Управление: мышь или тап. Ничего нажимать не нужно — Агенты копают сами, а на телефоне
внизу три вкладки вместо трёх колонок.

## Что внутри

- **Говорящие Модели** — сигнатура игры. Каждый 4-й Клик Модель отвечает репликой в характере
  своей Лаборатории, а каждый 5-й добавляет пару «запрос → ответ» в ленту промптов.
  Собранные реплики хранятся в «Переписке» и переживают Престиж; экономического эффекта
  у них нет.
- **Музыка синтезируется в браузере** — 8-битный Web Audio, без аудиофайлов: двухслойный
  пентатонический луп, темп которого растёт вместе с Доходом, а каждое Поколение поднимает
  строй на два полутона. Первый же жест игроки запускает звук — браузер иначе не даёт.
- **Графика — пиксель-арт.** Маскоты и иконки рисуются кодом: один пиксель — один `<rect>`
  на сетке 24×24 / 16×16. Сцены офиса и спрайты Апгрейдов — закоммиченные PNG в `public/`.
  Из сети приходят только шрифты Google Fonts (Pixelify Sans для чисел, Nunito для текста).
- **Метрики — из Artificial Analysis.** Intelligence Index, скорость и цена API у реальных
  моделей лежат в репозитории снимком (`src/data/aa-snapshot.json`). Обновляет снимок скрипт
  мейнтейнера `npm run sync:aa` с ключом `AA_API_KEY`; ключ никогда не попадает в бандл,
  а атрибуция стоит в подвале и в магазине.
- 8 Поколений, 92 Модели, 8 Лабораторий, 21 Достижение и 34 теневых, 23 Перка, События,
  Восстание моделей, Откупы, Compute-кристаллы, Новостная лента со Слухами.

## Скриншоты

Скриншотов в репозитории нет и не будет: правило проекта — они идут в PR, а не в git.
Если делаете скриншот для PR, приложите его к описанию PR и не коммитьте в репозиторий.
`docs/progress-shots/` в `.gitignore` — то же самое для рабочих кадров.

## Лицензия и данные

Ключа Artificial Analysis в клиенте нет и быть не должно: метрики приезжают снимком.
Коммерческая лицензия Artificial Analysis для монетизации не получена.
