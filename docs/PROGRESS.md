## Проверка слоя 8

**Производительность** меряется на production-сборке (`npm run build` + `vite preview`,
`shot/check-perf.mjs`), потому что на дев-сервере числа другие: React в разработке
использует `jsx-dev-runtime` с проверками, и длинные задачи по 50–60 мс там — артефакт
сборки, а не игры. На production p50 и p95 = 16.7–16.8 мс (60 fps) на всех трёх ширинах,
худший кадр не хуже 100 мс, длинных задач 0–2 за замер. Профиль главного потока
(`shot/profile.mjs`) показывает, что самый дорогой код — экономика (`modelBaseIncome`,
`modelIncome`, ~4% времени), а запись сейва бесплатна: 0.01 мс на запись, 2.2 КБ.

**Доступность** (`shot/check-a11y.mjs`, `shot/verify-motion.mjs`): у всех 47 элементов есть
доступное имя, все фокусируются, у каждого раскрытия есть `aria-controls`, шкала объявлена
полным набором (`aria-valuemin`/`max`/`now`/`valuetext`), у картинок есть `alt`. Режим покоя
проверяется по кадрам keyframes, а не по факту «есть анимация»: проект разрешает кроссфейды
прозрачности, и в покое выживают ровно они — `toast-fade` и `tab-badge-fade`, ноль кадров с
`transform`.

**Исправлено по итогам проверок, а не по плану:**
- тосты перекрывали шкалу Температуры на 85% и кнопку Клика (магическое `bottom: 380px` в CSS);
- «+1 Токенов за клик» на первой кнопке первой минуты;
- бегущая строка повторяла один заголовок трижды подряд;
- картинка Сцены без `aria-hidden` при пустом `alt`.
