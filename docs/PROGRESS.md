# Прогресс

Слои строго по порядку. После каждого — коммит.

- [ ] **Подготовка** — изучено, отснято, ресёрч, vision, решения
- [ ] **1. Механики и системы** — core loop, экономика, баланс, кривая сложности, Температура как система
- [ ] **2. Прогрессия и контент** — 30 минут цели, разблокировки, события, реиграбельность, тон
- [ ] **3. UX и поток** — онбординг 60 с, обратная связь, управление, меню, сейв, настройки, конец и рестарт
- [ ] **4. Game feel** — анимации, частицы, тряска, hit-stop, мгновенный отклик
- [ ] **5. Звук** — эффекты, процедурная музыка, динамика по ходу игры
- [ ] **6. Графика** — арт-направление, палитра, иконки, фоны, шейдеры
- [ ] **7. UI-дизайн** — типографика, сетка, компоненты, HUD, адаптивность
- [ ] **8. Полировка** — производительность, баги, крайние случаи, доступность, README

## Готово, когда всё одновременно

- [ ] Запускается без ошибок в консоли
- [ ] Новый игрок понимает, что делать, за 60 секунд
- [ ] У каждого значимого действия есть визуальный и звуковой отклик
- [ ] Есть цель и прогрессия минимум на 30 минут
- [ ] Температура заметна в первые две минуты, в механике, звуке и графике
- [ ] Визуальный стиль целен на всех экранах
