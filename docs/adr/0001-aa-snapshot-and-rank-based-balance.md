# Статический снимок Artificial Analysis и баланс от Ранга, а не от сырых метрик

Характеристики Моделей берутся с Artificial Analysis, но игра не ходит в их API в рантайме: скрипт синхронизации с ключом сохраняет снимок в JSON в репозитории, поверх которого лежит файл ручных правок и ручная нарезка Моделей по Поколениям. Игровые цена и Доход выводятся из Ранга Модели в Поколении (экспоненциальная лестница в духе Cookie Clicker, масштаб ×1000 на Поколение), а реальная цена $ даёт лишь модификатор в пределах ±30%.

Скорость (t/s) в баланс не входит и остаётся справочной величиной: AA публикует её для меньшинства Моделей, поэтому медиана по поколению равна нулю, и `softMod` отдавал бы ±30% тем, чью скорость измерили, остальным — ровно 1. Это артефакт разрежённости данных, а не разница скоростей. Доход — чистая лестница Ранга.

Снимок содержит только Модели, на которые ссылаются сиды: файл импортируется прямо в бандл, поэтому 690 записей AA были бы ~90 КБ публичных данных, из которых игра читает единицы. Сид, пропавший из выдачи AA, сохраняет прошлую запись, а не теряет значение. Значения в сидах — не «примерные», а снятые с AA на момент синхронизации: снимок может отсутствовать или устареть, а каталог обязан оставаться верным.

## Considered Options

- **Живой API из браузера** — невозможно: AA требует `x-api-key` и запрещает раскрывать его на клиенте.
- **Прокси с кешем** — требует бэкенда, а пересчёты Intelligence Index на стороне AA ломали бы баланс без релиза.
- **Сырые метрики как игровые числа** — Intelligence Index имеет сжатую, периодически перебалансируемую шкалу, а реальная цена API почти не коррелирует с качеством (DeepSeek умнее и дешевле Claude 3 Opus), что противоречит правилу «лучшие Модели стоят дороже».

## Consequences

- Обновление данных и добавление новых Моделей — это релиз игры, а не фоновое событие.
- Обязательна видимая атрибуция Artificial Analysis со ссылкой; монетизация потребует коммерческой лицензии AA.
- Скорость из AA не влияет на Доход, поэтому Апгрейд Модели «×2» остаётся единственным множителем Модели в забеге, а сбалансированная игра не может опираться на метрику, которую AA измеряет выборочно.
- Индекс AA пересчитывается и меняет Ранги без нашего участия, поэтому синхронизация — потенциально ломающее изменение баланса: после неё обязателен прогон тестов каталога, а не только `tsc`.
