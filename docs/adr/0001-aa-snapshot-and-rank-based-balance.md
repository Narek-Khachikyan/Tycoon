# Статический снимок Artificial Analysis и баланс от Ранга, а не от сырых метрик

Характеристики Моделей берутся с Artificial Analysis, но игра не ходит в их API в рантайме: скрипт синхронизации с ключом сохраняет снимок в JSON в репозитории, поверх которого лежит файл ручных правок и ручная нарезка Моделей по Поколениям. Игровые цена и Доход выводятся из Ранга Модели в Поколении (экспоненциальная лестница в духе Cookie Clicker, масштаб ×1000 на Поколение), а скорость и реальная цена $ дают лишь модификаторы в пределах ±30%.

## Considered Options

- **Живой API из браузера** — невозможно: AA требует `x-api-key` и запрещает раскрывать его на клиенте.
- **Прокси с кешем** — требует бэкенда, а пересчёты Intelligence Index на стороне AA ломали бы баланс без релиза.
- **Сырые метрики как игровые числа** — Intelligence Index имеет сжатую, периодически перебалансируемую шкалу, а реальная цена API почти не коррелирует с качеством (DeepSeek умнее и дешевле Claude 3 Opus), что противоречит правилу «лучшие Модели стоят дороже».

## Consequences

- Обновление данных и добавление новых Моделей — это релиз игры, а не фоновое событие.
- Обязательна видимая атрибуция Artificial Analysis со ссылкой; монетизация потребует коммерческой лицензии AA.
