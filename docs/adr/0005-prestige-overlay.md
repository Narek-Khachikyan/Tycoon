# Оверлей Престижа

Полноэкранный отклик на Престиж в духе экрана вознесения Cookie Clicker: затемняющая вуаль, карточка нового Поколения с тикающим Compute и восходящие искры (`PrestigeOverlay`, данные — в `burst` стора, UI-слой, в сейв не пишется).

## Драматургия 2.8 секунды

Всё разведено по фазам вместо фронтлоада: вуаль 0–350 мс, карточка с задержкой 180 мс и попом, тиканье Compute `0 → N` за 1.2 с со старта на ударе, выход кроссфейдом 0.22 с вместо обруба. Клик гасит раньше, но тоже через выход. Счётчик пишет прямо в DOM-ноду через rAF — тем же приёмом, что счётчик Токенов, без ре-рендера на кадр. Звук продлён 0.4 с → ~1.1 с вторым слоем-арпеджио (мажорный треугольник C–E–G–C против квадратного минора Достижения, чтобы два торжества не звучали одинаково).

Яркой вспышки на весь экран нет намеренно: это триггер фоточувствительности, вуаль только затемняет. Ударное кольцо-квадрат пробовалось и убрано — выглядело чужим. Искры идут `steps(14)` вместо `ease-in` (разгон вверх физически неверен) и заканчиваются до гашения оверлея.

При `reducedMotion` остаются лишь кроссфейды opacity, искры не создаются вовсе, число показывается сразу финальным — fade не вестибулярный триггер, в отличие от scale/translate/shake.

## Considered Options

- **Яркая вспышка на весь экран** — отклонено. Триггер фоточувствительности, прямо противоречит шкале движения в `index.css`.
- **Canvas-конфетти** — отклонено. Второй цикл анимации и новый пайплайн ради одноразового момента; маскоты рисуются SVG-rect, сцены — committed PNG, кодогенерация остаётся в CSS.
- **Генерация картинки внешней моделью** — отклонено. Нет доступа из harness, а ассету понадобились бы коммит, лицензия и место в бандле ради фона на 2.6 секунды.
- **Квадратное shockwave-кольцо** — попробовано и убрано после видео: чужеродный элемент поверх пиксельной сетки.

## Consequences

- Шкала «покупка < достижение < престиж» теперь выдержана: у Престижа есть своя вершина (тикающий Compute), а не только 90 мс тряски.
- Тряска корня осталась, но идёт под вуалью и почти не читается — кандидат на удаление при следующем касании `App.tsx`, не раньше.
- Соседние решения: [ADR-0004](0004-pair-synergy-and-generation-perks.md) — механики вовлечения; [ADR-0003](0003-pixel-font-only-for-logo-and-numbers.md) — числа в оверлее идут через `Num`/`formatNumber`.
