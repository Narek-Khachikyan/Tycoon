# Прогрессия и реиграбельность: приёмы жанра + план 0–30+ минут

## Приёмы с примерами

**Три горизонта целей.** У игрока всегда видны цели на секунды (следующая покупка), минуты (дорогой юнит/Апгрейд) и десятки минут (сброс, эра). Cookie Clicker: юнит → накопление → асценсия; NGU Idle доводит до предела параллельными тикерами (exp, яма, приключение). Вывод: в магазине всегда подсвечен «следующий Апгрейд» — экран без видимой цели убивает быстрее медленного баланса.

**Новая система каждые ~5 минут.** Cookie Clicker открывает мини-игры (сад, гримуар) в середине, переизобретая игру. Universal Paperclips — эталон: 3 стадии (скрепки → доверие/вычисления → космос), каждая ломает прежнюю экономику. A Dark Room: огонь → комната → деревня → карта, каждый шаг меняет жанр. Realm Grinder — фракции, Kittens Game — дерево технологий. Нам: Престиж, Восстание, Лицензию, Compute-кристалл нельзя выдавать разом — разносятся по минутам.

**Запланированная непредсказуемость.** Золотые печеньки (комбо «Frenzy + Lucky») превращают афк в охоту; Grandmapocalypse добавляет риск: красные чаще вредят, но дают джекпот. Наши Золотой Токен, Глюк, красные События — та же схема; главное, чтобы события комбились (Волна хайпа × Клик-рывок), а не просто выпадали.

**Ачивки как экономика + теневые для ветеранов.** В Cookie Clicker ачивки дают молоко (множитель) — коллекция и есть прогресс; теневые («не кликать») — еда для спидраннеров. Наш Датасет (Достижение = Доход) — то же верное решение; теневые держать «странными», без эффекта.

**Престиж: первый сброс рано, каждый слой — механика.** Cookie Clicker: асценсия + второй слой (сахарные комки); NGU: rebirth → evil → sadistic с новыми условиями. Правила: первый Престиж за 30–60 минут, иначе до него не доживают; слой меняет игру, а не только ×N. Наши Перки (автоклик, оффлайн-ставка, скидки) — правильный путь: Перк меняет стиль Забега.

**Тон как бесплатный контент.** Cookie Clicker — абсурдная лента + хоррор бабушек; Paperclips — экзистенциальная история ИИ; A Dark Room — текст и есть прогрессия. Наши лента + Слухи + Справка AA — тот же инструмент: шутка каждые ~15 с дешевле любого юнита, а Финал контента («продолжение выйдет с новыми моделями») превращает конец каталога в обещание.

## План 0–30+ минут

| Время | Что разблокируется |
|---|---|
| 0–1 мин | Клики → первый Агент за <1 мин. Видны цели: «Апгрейд Клика», «вторая Модель». Первая новость в ленте. |
| 1–3 мин | Вторая Модель + первая Синергия Лаборатории. Первый Апгрейд Клика. |
| 3–6 мин | Первый Апгрейд Модели (порог Агентов, ×2). Первый Золотой Токен (Грант/Волна хайпа). Первое Достижение → видимый Датасет. |
| 6–10 мин | Первый Глюк (лопнуть, вернуть с избытком). Клик-рывок ×777. Третья Лаборатория. Слух с выплатой. |
| 10–15 мин | Апгрейды Синергии, Прорыв флагмана. Намёк: «купи Флагмана — откроется Престиж». |
| 15–22 мин | Восстание моделей: красные События + Лобби (Откуп на время). Комбо событий. Кристалл тикает фоном. |
| 22–28 мин | Покупка Флагмана → открыт Престиж. Выбор: уйти сразу или дофармить (подсказать цену: «ещё N Compute за 5 минут»). |
| 28–35 мин | Первый Престиж → Поколение 2 + Compute → первый Перк. Второй Забег в 2–3× быстрее — сила сброса ощущается. |
| 30+ мин | Цикл Забегов: Лицензия, теневые Достижения, особые Перки Поколений. Мета-цели: Финал контента, «Полный зоопарк», 5 престижей. Каждый Забег — одна новая система, не только цифры. |
