# Визуал, звук и UI — исследование (05)

Рамки: только CSS/SVG/canvas, WebAudio-синтез, Pixelify Sans (числа) + Nunito (текст). База задана ADR-0002/0003: тёмный тёплый тауп, акцент Поколения в `--accent-color`, PNG-маскоты 24×24 (`pixelated`), 4 PNG-сцены, анимации только `transform`/`opacity` с fade-двойниками под `reducedMotion`.

## 1. Арт-направления (все — поверх текущей базы)

1. **Тёплая серверная (текущее, углубить).** `#100E0C/#1A1714/#221E1A`, текст `#F0EBE3`, акцент поколения (напр. `#FF7A2F`); семантика: `#E8A33D/#4FBF6A/#E15959`. Нулевой рескин — маскоты и сцены уже нарисованы под неё; акцент поколения показывает прогресс «офис богатеет».
2. **Cozy CRT / фосфорный терминал.** База `#0B0F0C`, панель `#141A15`, фосфор `#33FF66` + янтарь `#FFB000`, текст `#9DB3A0`. Кликер = «терминал, печатающий Токены»; сканлайны и свечение дёшево делаются CSS (`repeating-linear-gradient`, `text-shadow`).
3. **Полночный синт-лаб.** База `#0D0D1A`, панель `#171726`, неон `#7C5CFF`→`#00E5FF`, золото только Престижу `#E8A33D`. 8 Поколений = 8 неоновых оттенков, смена читается мгновенно; тёмно-синяя подложка усиливает золотые события.
4. **Бумажный пиксель.** `#F0EBE3` + чернила `#221E1A`, штампы `#B91C1C/#1D4ED8`. Единственный светлый вариант, но требует перерисовки сцен и маскотов и ломает ADR-0002 — только при полном рескине.

## 2. Game feel на CSS/canvas

- **Сквош/поп (уже есть, не расширять):** клик `scale(1.06,0.94)` 0.13 с, строка покупки `scale(1.045)` 0.26 с пружиной `cubic-bezier(0.34,1.56,0.64,1)`; тряска — только Престиж (10 px/0.45°, 90 мс) + провал яркости вместо вспышки.
- **Частицы:** искры покупки (8 шт, 0.56 с), веер Достижения (24 шт, 0.72 с), моты Престижа (`steps(14)` — пиксель-стилистика без кода). Перезапуск — `key={nonce}`-перемонтированием; `<canvas>` — лишь если частиц >100, кадры гонит существующий тик 50 мс (второго rAF/интервала не заводить).
- **Easing-словарь:** нажатие `cubic-bezier(0.2,0,0.2,1)` 0.11 с; отпускание — пружина 0.24 с; тосты: вход 0.3 с `ease-out`, уход 0.18 с без торможения; флоатеры `+N` — `cubic-bezier(0.18,0.89,0.32,1.28)` 0.9 с.
- **Живой фон дёшево:** пыль `mote-drift` 6–9 с alternate, маскоты с отрицательными `animation-delay` (расфазировка), параллакс — `translate3d` одного слоя.

## 3. Процедурное аудио (расширение `sound.ts`)

- **Музыка — 2 слоя:** пэд-бас (sine/triangle 55–110 Гц, lowpass 400–800 Гц, gain ~0.04) + арпеджио по пентатонике C–D–E–G–A (square, lowpass ~2000 Гц, gain ~0.04 — фальшь невозможна). Шедулер — `setInterval` 100 мс с lookahead 0.2 с, стоп при `muted`/фоне.
- **Адаптивность:** 2-й слой с 3-го Поколения; темп 90→120 BPM от логарифма Дохода; смена Поколения = транспонирование +2 полутона; событие = дакинг музыки (×0.3 на 2 с) + стингер (есть: E5–B5–E6 square).
- **Тембры one-shot (образец уже в коде):** клик square 320→740 Гц 0.05 с; отказ — низкий buzz square 140→90 Гц (не путать с покупкой); удар/глитч — 0.1 с white-noise через bandpass 1–3 кГц, gain 0.05; дрон — sine 80 Гц + LFO 0.5 Гц. Мастер-gain ≤0.15, все огибающие — экспонента в `0.001`; `suspended` = no-op, не баг.

## 4. UI-паттерны под наш layout (`THREE_COL_MIN` = 300+340+360 = 1000 px)

- **HUD:** липкая шапка — баланс (Pixelify Sans), Доход/сек, Поколение; под ней лента новостей с паузой. Цифры всегда видны, лента даёт «мир живёт».
- **Магазин (340–440 px):** строки Модель = цена + Доход + полоса до Агента; bulk ×1/×10/×100/MAX (`aria-pressed`); недоступное — `dashed`-рамка, но цена и условие видны (≥4.5:1); пульс бейджа при доступном Апгрейде. Ширина колонки не зависит от вкладки.
- **Клик (300–380 px):** большая кнопка с `pulse-glow`, флоатеры `+N` через rAF в DOM-узел (мимо React), Золотой Токен пульсирует 1.6 с.
- **Офис (тянется):** сцена `floor(generation/2)`, HUD-полоса на затемнении, прыжок маскота при покупке своей Лаборатории.
- **Престиж:** подтверждение (превью «+N Compute», красным — необратимость) → вуаль-празднование (затемнение + `pop`-карточка + моты). Финал: та же вуаль без вайпа.
- **<1000 px:** одна колонка + нижний таб-бар (Промпт/Офис/Магазин), переключение — `toast-fade` 0.15 с; атрибуция AA в Footer в обоих режимах.

## Рекомендованная связка

**Направление 1 (тёплая серверная) + акценты Поколений через `--accent-color`** — нулевой рескин, движение/контраст уже выверены. Звук — **двухслойный пентатонический луп (бас-sine + арп-square, дакинг под события)** поверх существующих SFX, мастер ≤0.15. UI — **3 колонки ≥1000 px / таб-бар ниже**, двухшаговый Престиж.
